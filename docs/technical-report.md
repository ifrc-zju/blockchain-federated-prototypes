# 区块链协作的联邦原型学习：方法与补充实验

## 研究问题与实现

异构客户端的类别分布和样本数量不同，可能造成局部表示及原型估计偏差。本实现依据BF4Hg论文的相关机制，将跨客户端语义原型加权表示协作与小样本原型收缩接入区块链状态约束流程。链上登记任务、客户端、轮次以及模型和原型摘要，链下校验提交文件、重算局部统计并聚合。

语义原型加权方法使用全局类别原型生成类别间相似度权重，参与客户端的对比学习目标。原型收缩根据本地类别样本数量，将局部原型与上一轮先验结合；没有观测的类别不会凭空生成本地观测。合约拒绝未授权客户端、错误轮次、错误先验、重复提交、不完整聚合和错误提交集合根。

代码是对上述机制的独立补充实现，采用小型全连接网络，未实现论文全部组件。链上摘要用于关联数据内容与状态，不代表浮点计算正确性证明；数值正确性由独立复核器检查。

## 历史实验配置

EMNIST Balanced共47类；每类抽取100张训练、40张测试图像，共4,700／1,880张，保持官方训练与测试集合分离。样本种子2300；划分和初始化种子2301、2302、2303。6客户端采用Dirichlet α=0.2划分，同种子的各比较组使用相同划分。

模型为784→64 tanh→32线性嵌入→47类别头，像素除以255，无数据增强。SGD无动量，学习率0.03，权重衰减1e-5，batch为32；10轮训练，每轮1个本地epoch，所有客户端参与。WPC参数τ=0.15、α=0.5、λ=0.7，收缩参数μ=10，IRD和MHN关闭。

主指标是第10轮全局余弦最近原型分类准确率。原型分类出口属于补充实现的评估选择。统计以3次独立种子为单位，不以轮次或客户端类别单元充当独立重复。

## 历史实验结果

|组|机制|原型准确率（均值±样本SD）|CE头准确率（均值±样本SD）|
|---|---|---:|---:|
|F|CE／FedAvg|34.80 ± 2.17%|32.55 ± 2.40%|
|SC|普通监督对比，α=0|44.79 ± 1.50%|36.74 ± 2.20%|
|W|WPC，无收缩|30.99 ± 1.87%|28.10 ± 1.93%|
|S|原型收缩，无WPC|34.04 ± 1.36%|32.55 ± 2.40%|
|WS|WPC与原型收缩|29.63 ± 1.82%|28.10 ± 1.97%|

本配置未观察到WPC或原型收缩带来的准确率提升。小样本类别（n=1–5）的原型估计误差种子均值由0.223755增至0.511076，同样不支持估计误差下降。局部模型与上一轮全局模型的表示坐标可能存在漂移，但这一解释尚未经独立因果实验验证。

完整逐种子、逐轮与配对统计见[公开数据](../data/published-results/)。结果来自历史主套件main_20260910T103853Z_3428e9，不是本次发布的单轮运行成绩。

## 复核与适用范围

历史实验包括15组运行和165份轮次状态，独立复核重算900次客户端训练更新，参数最大绝对差为0；同时核对1,177笔真实测试链交易，其中1,171笔成功、6笔为预期回退。

发布副本的验证另见[VALIDATION.md](VALIDATION.md)。这些结果支持指定配置下的机制实现、链上链下关联和数值一致性，不代表完整BF4Hg性能复现、真实跨机构部署或优于基线。研究来源、数据来源与版本变化见[SOURCES.md](SOURCES.md)。
